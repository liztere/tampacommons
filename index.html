About This Project

An open directory of local businesses, organizations, co-ops, clubs, and other resources to help you reconnect locally. With the aim to lessen dependence on corporate and government entities. Similar things like this exist, this is just an effort to further consolidate, improve accessibility, and simply improve on technical functionality. If you have real development background or expertise/creativity on human interface design, you are encouraged to contribute to the project on GitHub.

Visit the sister site Regenerate Tampa Bay for more indepth content related to the ethos of this project.

Add a resource

If you know of a farm, mutual aid group, activist organization, native plant nursery, or other community resource that should be listed here, submit it. A volunteer will review and add it within a few days.

Keep the commons alive

This directory is free.
It doesn't have to be costly.

Tampa Commons has no ads, no corporate backing, and no paywalls. Hosting, the domain, and volunteer moderation time cost real money. If this directory has been useful to you, consider supporting it and the creator/maintainer. If/when other developers begin to help maintain this site, donation reception will be switched to Open Collective.
